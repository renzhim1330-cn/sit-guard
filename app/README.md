# 坐姿小卫士 — 运行说明

按 `.scratch/posture-app/spec.md` 实现的儿童坐姿提醒 MVP（纯前端）。

## 怎么运行

1. 用 **Chrome 或 Edge** 浏览器打开 `app/index.html`（双击即可，无需安装任何东西）。
   - 手机/平板演示：把 `app/` 目录部署到任意 HTTPS 静态托管（GitHub Pages、Vercel 等），或本机 `localhost`。
   - 注意：**必须 HTTPS 或 localhost** 才能使用摄像头；`http://局域网IP` 不行。
2. 首次打开需联网下载 MediaPipe 模型（约 6 MB，之后有缓存）。
3. 允许摄像头权限 → 点「开始学习」→ 5 秒倒计时「请坐正，看着屏幕」→ 自动记住你的标准坐姿 → 进入专注黑屏。

## 功能速览

- **检测**：驼背 / 头过低 / 侧倾 三类，全程本机推理，视频不上传
- **自动校准**：点「开始学习」后 5 秒倒计时（请坐正）→ 取末段均值自动记住标准坐姿（质量门：检测到人且基准不歪，否则提示重来）；机位挪动后重新开始学习即自动重校；「⚙️ 参数设置」里有手动「重新校准」入口（骨架演示模式内仍可手动校准）
- **提醒**：连续超标 3.5 秒播语音——默认用内置 mp3（`app/audio/`，晓晓声线，移动端无需 TTS 引擎）；可在「提醒语音」卡片为每一句单独录音，换成家长/老师真实声音
- **参数设置**：页脚「⚙️ 参数设置」可动态调整判定阈值与提醒频率（立即生效、自动保存在本机），含「宽松 / 标准 / 严格」三档灵敏度预设与恢复默认
- **学习时段**：默认 40 分钟倒计时，可暂停/继续；孩子离开画面 ≥5 秒自动暂停并显示「看不到你啦」
- **专注模式**：开始学习后自动进入——绿色圆环 5 秒倒计时（右下角「取消」）→ 屏幕全黑（仅极暗吉祥物剪影 + 左下角「退出专注」按钮），检测与语音提醒照常，孩子不被屏幕内容分心；退出黑屏可再点「进入专注」重新进入；黑屏靠 **Screen Wake Lock** 防自动锁屏，无唤醒锁的设备进入前会提示
- **小结与历史**：结束时显示 良好时长/提醒/坐正表扬；最近 7 次记录存在浏览器本地
- **骨架演示模式**：页脚按钮，展示摄像头画面 + 关键点叠加（参赛/展示用）

## 离线分析（调阈值 / 回归基线用，票 08）

浏览器打开 `app/analyzer.html`（Chrome / Edge 双击即可，无需部署、无需摄像头）：

1. 选本地测试视频（拍摄清单与机位见 `test-assets/README.md`，素材放 `test-assets/`）→ 点「开始收集」，本地逐帧检测（与 App 同一 MediaPipe 模型 + 同一 `measure.js` 度量公式，数值可直接迁移）
2. 自动取开头「标准坐」段为基准；也可在轨迹图上按住拖动框选任意时段改基准
3. 点「自动切分」按「标准→动作→回正」台阶分档命名（驼背-轻/中/重…），或手动在偏离图上拖选区间
4. 输出：各档偏离分布（均值 / P25 / P50 / P75 / max）、每姿态偏离直方图、阈值建议 t1/t2（按轻↔中、中↔重分界）；红竖线 = 按当前阈值（含迟滞 / 宽限 / 冷却，同一 `engine.js`）会触发提醒的帧；区间名含「正常」的段会统计误报帧数与触发次数
5. 「导出 CSV」留存每帧数据，作为以后改算法后的回归对比基线

全程本地处理，视频不上传。分析页产出的建议值已按素材校准并更新 `app.js` 的 `CFG` 与「标准」预设（票 05/08）；以后改算法后重跑分析页对比 `test-assets/analysis-results.md` 即得回归基线。

## 文件结构

- `index.html` — 页面（加载 MediaPipe CDN）
- `style.css` — 方案 B「学习驾驶舱」样式 + 吉祥物
- `measure.js` — 关键点 → 三个度量（world landmarks 优先）
- `engine.js` — 判定状态机（状态带/迟滞/宽限/冷却/表扬）
- `voice.js` — 语音文案库与播放（录音覆盖 > TTS）
- `app.js` — 摄像头、检测循环、会话、界面绑定
- `analyzer.html` / `analyzer.js` — 离线回放分析页（选本地视频逐帧检测，输出偏离分布与阈值建议；调阈值 / 抗误报回归用）

## 已知限制（创意作品定位）

- 浏览器需支持 WebGL2（iOS Safari 15+ / Android Chrome 56+）
- 阈值（驼背 8°/12°、头过低 10%/16%、侧倾 6°/12°）为素材校准值（票 05/08，见 `test-assets/analysis-results.md`），可在 `app.js` 顶部 `CFG` 调整
- 检测跑在主线程（官方示例为 Web Worker），中端设备实测 ≥20 FPS；如需进一步优化再迁移
- **专注模式**：防自动锁屏需要 **Screen Wake Lock**（iOS Safari 16.4+ / Android Chrome 84+，需 HTTPS）；不支持的设备进入前会提示「可能锁屏」（建议系统自动锁屏设为永不）。系统锁屏后浏览器页面会被挂起、检测中断——这是平台限制，纯 Web 无法规避；锁屏恢复后 App 会自动重取摄像头并继续（页面被系统刷新时需重新校准，会弹出提示）
- 黑屏仅省电于 OLED 屏（LCD 背光常亮）；专注模式的初衷是防分心而非省电
