# 坐姿小卫士 — 运行说明

按 `.scratch/posture-app/spec.md` 实现的儿童坐姿提醒 MVP（纯前端）。

## 怎么运行

1. 用 **Chrome 或 Edge** 浏览器打开 `app/index.html`（双击即可，无需安装任何东西）。
   - 手机/平板演示：把 `app/` 目录部署到任意 HTTPS 静态托管（GitHub Pages、Vercel 等），或本机 `localhost`。
   - 注意：**必须 HTTPS 或 localhost** 才能使用摄像头；`http://局域网IP` 不行。
2. 首次打开需联网下载 MediaPipe 模型（约 6 MB，之后有缓存）。
3. 允许摄像头权限 → 点「校准 / 重新校准」→ 孩子坐正后点「我坐好了」→ 点「开始学习」。

## 功能速览

- **检测**：驼背 / 头过低 / 侧倾 三类，全程本机推理，视频不上传
- **提醒**：连续超标 3.5 秒播语音（默认用系统语音合成朗读；可在「提醒语音」卡片为每类录音，换成家长/老师真实声音）
- **学习时段**：默认 40 分钟倒计时，可暂停/继续；孩子离开画面 ≥5 秒自动暂停并显示「看不到你啦」
- **小结与历史**：结束时显示 良好时长/提醒/坐正表扬；最近 7 次记录存在浏览器本地
- **骨架演示模式**：页脚按钮，展示摄像头画面 + 关键点叠加（参赛/展示用）

## 文件结构

- `index.html` — 页面（加载 MediaPipe CDN）
- `style.css` — 方案 B「学习驾驶舱」样式 + 吉祥物
- `measure.js` — 关键点 → 三个度量（world landmarks 优先）
- `engine.js` — 判定状态机（状态带/迟滞/宽限/冷却/表扬）
- `voice.js` — 语音文案库与播放（录音覆盖 > TTS）
- `app.js` — 摄像头、检测循环、会话、界面绑定

## 已知限制（创意作品定位）

- 浏览器需支持 WebGL2（iOS Safari 15+ / Android Chrome 56+）
- 阈值（驼背/侧倾 8°/12°、头过低 12%/20%）为初值，可在 `app.js` 顶部 `CFG` 调整
- 检测跑在主线程（官方示例为 Web Worker），中端设备实测 ≥20 FPS；如需进一步优化再迁移
