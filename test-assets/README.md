# 坐姿素材拍摄指南（票 05）

拍这套素材的目的：量化「轻度 / 中度 / 重度」每种不良坐姿对应的**偏离值**，
把 `8°/12°`、`12%/20%` 这些初值阈值换成**有数据支撑**的值，并留下抗误报回归基线。
视频存放在本目录，全部本地处理、不上传。

---

## 一、拍之前：准备工作

**设备**
- 就用**实际使用的同一台设备**（手机或平板），摆在实际使用的书桌 / 位置上
  ——机位必须和真实使用一致，否则阈值不迁移
- 用支架立起来，摄像头在孩子**正前方**、**与脸平齐或略高**（轻微俯视），
  距离约 1 米，画面能框住**头到腰**
- 手机竖着、平板横着都可以（检测用 3D 坐标，与横竖无关），但
  **一旦开拍，全程不要移动设备**
- 关掉人像模式 / 背景虚化 / 美颜滤镜，用**普通视频模式**，
  分辨率默认（1080p 即可）、不要慢动作

**光线**
- 顺光或侧光：孩子**面对或侧对**光源（窗户 / 台灯）
- 绝对避免逆光（背对窗户）——逆光时关键点大面积丢失，素材作废
- 不开闪光灯；自然光或顶灯都可以

**孩子**
- 穿**短袖或贴身的衣服**，能看出肩部轮廓；不要高领、不要大围巾
- 头发**不要挡脸**（鼻子关键点必须可见）；不戴帽子
- 全程同一个孩子

**拍前快速自检（30 秒）**
打开 App 的**骨架演示模式**看一眼：画面里能否同时看到鼻、双耳、双肩、双髋的
关键点完整贴住身体？能看到 → 机位 OK；只能看到脸 → 太近了，往后挪。

## 二、每条视频的通用拍法（最关键的两条规则）

**规则 1：每条视频开头，先让孩子坐标准 3–5 秒再开始做动作。**
判定是「偏离校准基准」——离线分析需要从开头这段标准坐姿提取基准，
没有它，后面所有数据都无法计算偏离。

**规则 2：用「循环式」拍法，档位之间有标准态分隔：**

> 标准坐 5 秒 → 做动作 → 回正坐标准 3 秒 → 做更重的动作 → 回正坐标准 3 秒 → … → 最后回正坐标准 5 秒

这样轨迹上每一档是一个清晰的"台阶"，中间的标准段既是参照基准、又把各档隔开，
离线能自动切分并读出"轻度≈几度、中度≈几度、重度≈几度"。

家长在边上**口头引导节奏**（"再弯一点……好，保持住……好，坐直"），
孩子不用精确控制幅度，自然表现即可。

## 三、要拍的 5 类场景

**① 标准坐姿（基准）** —— 1 条，15–20 秒
自然端坐：背挺、头正、眼睛看屏幕（就是校准时的姿态）。不用军姿，平时写作业最好的状态即可。

**② 驼背（轻 / 中 / 重）** —— 1 条循环式视频，20–30 秒
从标准开始 → 微微含胸（轻度，保持 5–6 秒）→ 回正 → 弯得更明显（中度）→ 回正 →
弓到最大（重度，快趴下那种）→ 回正结束。
注意：驼背时**头会自然跟着低**，不用刻意仰头，自然发生就行。

**③ 头过低（轻 / 中 / 重）** —— 1 条循环式视频，20–30 秒
从标准开始 → 微微低头（眼睛还看着屏幕，轻度）→ 回正 → 低头更多（中度）→ 回正 →
下巴贴近桌面（重度）→ 回正结束。
注意：**身体保持挺直、只低头的动作也要录**——这能检验"头过低"和"驼背"
两个指标是否真的分开（这正是之前想解耦的）。

**④ 侧倾** —— 2 条循环式视频（歪头、歪身分开录），各 15–20 秒
- 歪头：标准 → 头往左肩歪（保持 5–6 秒）→ 回正 → 头往右肩歪 → 回正
- 歪身：标准 → 整个身体往左斜 → 回正 → 往右斜 → 回正
歪头和歪身是两种动作，分开录才能分别验证。

**⑤ 正常小动作（抗误报）** —— 1–2 条，30–60 秒
让孩子**真实地写作业**，期间自然发生：喝水、翻书、抬头看屏幕、擦一下桌子、挠挠头……
不要摆拍，越自然越好。这条用来验证"正常动作不能误报提醒"。

---

## 四、拍完之后的检查

- 每条回放一遍：画面里全程能看到头 + 肩 + 腰，没有出画、没有遮挡
- 光线均匀、无逆光
- 孩子动作节奏符合「标准 → 动作 → 标准」的循环

## 六、常见错误避坑清单

| 错误 | 后果 | 避免 |
|---|---|---|
| 设备太近只拍到脸 | 没有肩 / 髋关键点，驼背无法测 | 后退到能框住头到腰 |
| 逆光拍摄 | 关键点丢失，素材全废 | 面对 / 侧对光源 |
| 每段开头没坐标准 | 没有基准，偏离无法计算 | 记住规则 1 |
| 拍的过程中挪动设备 | 各段坐标系不一致 | 固定后全程不动 |
| 开了人像模式 / 美颜 | 姿态估计可能受干扰 | 普通视频模式 |
| 孩子戴帽子 / 头发挡脸 | 鼻子关键点不稳 | 露脸、露肩 |
