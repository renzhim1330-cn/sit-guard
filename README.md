# 坐姿小卫士 (sit-guard)

面向 6–12 岁儿童的学习坐姿提醒 Web App。用手机 / 平板 / 电脑的前置摄像头实时检测不良坐姿，以温和语音提醒孩子坐正，帮助保护视力、预防驼背。

**纯前端，无后端、无数据库、无任何付费服务。** 检测模型在浏览器本地运行，视频画面不出设备，隐私完全留在本地。

---

## 它能做什么

- **检测三种不良坐姿**：驼背（躯干前倾）、头过低（头离屏幕过近）、侧倾（歪头 / 歪身）
- **自动校准**：点「开始学习」后 5 秒倒计时「请坐正」→ 自动记住标准坐姿基准；机位挪动后重新学习即自动重校
- **温和不唠叨的提醒**：连续超标才提醒（宽限计时），提醒间隔受冷却保护，语音文案随机轮换不重复
- **坐正表扬**：孩子改正并稳定保持后播放表扬语音，形成正向激励
- **专注模式**：学习时段自动进入纯黑屏，只保留语音反馈，减少屏幕干扰；Screen Wake Lock 防自动锁屏
- **学习小结与历史**：每次学习结束统计良好时长 / 提醒次数 / 表扬次数，本地保留最近 7 次记录
- **骨架演示模式**：摄像头画面 + 姿态关键点叠加，用于演示检测效果
- **家长参数面板**：三档灵敏度预设（宽松 / 标准 / 严格）+ 逐项微调，均可本地持久化

## 快速开始

### 方式一：本地双击（电脑）

用 **Chrome 或 Edge** 双击打开 `app/index.html` 即可，无需安装任何东西。

### 方式二：手机 / 平板

把 `app/` 目录部署到任意 HTTPS 静态托管（GitHub Pages、Vercel 等），或本机 `localhost` 访问。

> 注意：摄像头要求安全上下文（HTTPS 或 localhost）。`http://局域网IP` 无法使用摄像头。

### 首次使用

1. 允许摄像头权限（首次需联网下载 MediaPipe 模型约 5.5 MB，国内访问 Google Cloud Storage 较慢，约需 4～7 分钟；下载完成后会缓存，之后再打开只需几秒）
2. 点「开始学习」→ 5 秒倒计时「请坐正，看着屏幕」
3. 自动记住标准坐姿 → 进入专注黑屏开始检测
4. 结束时查看本次学习小结

### 语音提醒（家长可定制）

默认使用内置 mp3 语音（晓晓声线，见 `app/audio/README.md`）。可在「提醒语音」面板为每一条录音，换成家长 / 老师的真实声音，优先级：**家长录音 > 内置 mp3 > 系统 TTS > 提示音**。

## 检测原理

1. **MediaPipe Pose Landmarker**（浏览器 GPU/CPU 推理）从每帧提取 33 个身体关键点
2. **`measure.js`** 将关键点转换为三个度量：驼背角度 / 头过低比例 / 侧倾角度（优先用 3D world landmarks，归一化坐标兜底）
3. **`engine.js`** 计算「偏离校准基准」的绝对值，经状态带（正常 / 疑似 / 超标）+ 迟滞滤波 + 宽限计时 + 冷却控制后决定是否提醒
4. **`voice.js`** 播放提醒 / 表扬语音

所有计算都在本地设备完成，视频帧永不上传。

## 开发方式

本作品采用 **Matt Pocock 工程技能体系** 引导的人机协同开发模式（DeepSeek Harness Vibe Coding）：**人识别痛点与创意，AI 实现功能**。从需求澄清、技术选型、方案设计、代码实现到测试验证全流程可追溯。

### 主要技术

- **姿态估计**：MediaPipe Pose Landmarker（WASM + 浏览器 GPU 加速）
- **前端**：原生 HTML / CSS / JavaScript (ES Module)，无框架依赖
- **语音**：edge-tts（zh-CN-XiaoxiaoNeural）预生成 mp3
- **持久化**：浏览器 localStorage（校准基准 / 参数 / 学习历史）
- **分析工具**：Python (mediapipe) + `analyzer.html` 离线逐帧回放，验证阈值与抗误报

## 测试与调参

姿态模型是预训练的 MediaPipe 模型（从 CDN 下载），**不支持也不需要对模型重新训练**。但你可以**用自己的视频校准判定阈值**，让提醒更适合自家孩子、自家设备、自家机位和光线——这正是项目设计的调参闭环。

> 阈值依赖机位与光线：别人录的素材校出来的值，换设备 / 换位置就不准了。用自己的设备、放在真实使用的书桌上录，校出来的阈值才最贴合。

### 调参工作流：录制 → 分析 → 配置

**① 录制自己的测试视频**

按 `test-assets/README.md` 的拍摄指南录：
- 用实际要用的那台设备，固定机位（摄像头在孩子正前方、框住头到腰），全程不动
- 避免逆光、不开美颜 / 人像模式
- 每段开头先坐标准 3–5 秒（作为基准），再「标准 → 动作 → 回正」循环式拍
- 覆盖：标准坐姿 / 轻中重驼背 / 轻中重低头 / 歪头 / 歪身 / 正常写作业小动作

**② 用 `app/analyzer.html` 离线分析**

浏览器双击打开 `app/analyzer.html`（无需部署、无需摄像头），选本地视频：
- 用**与 App 完全相同**的 MediaPipe 模型 + `measure.js` 度量公式 + `engine.js` 判定引擎逐帧检测
- 自动取开头「标准坐」段为基准（也可在轨迹图上框选改基准）
- 输出各姿态偏离分布（均值 / P25 / P50 / P75 / max）、每姿态直方图
- 按当前阈值（含迟滞 / 宽限 / 冷却）模拟提醒，标出触发帧，正常段统计误报
- 给出阈值建议 t1/t2，可调阈值后重看提醒模拟效果
- 导出 CSV 留存，作为以后改算法后的回归基线

**③ 把校出来的参数配置进 App**

- **临时调整**：App 内「⚙️ 参数设置」面板逐项微调（三姿态阈值、宽限时间、提醒冷却），立即生效并保存到浏览器本地
- **永久修改默认值**：改 `app.js` 顶部 `CFG`（app.js:9-16），重新打开即用新默认值

`test-assets/` 已含 7 段真人测试视频与现成的分析结果（`test-assets/analysis-results.md`），可直接复现整条管线。

## 已知限制

- 需 WebGL2（iOS Safari 15+ / Android Chrome 56+）
- 检测跑在主线程（官方示例为 Web Worker），中端设备实测 ≥20 FPS
- 专注模式防自动锁屏依赖 Screen Wake Lock（iOS Safari 16.4+ / Android Chrome 84+）；不支持的设备进入前会提示
- 系统锁屏后浏览器页面会被挂起、检测中断，这是平台限制，纯 Web 无法规避；恢复后 App 会自动重取摄像头
