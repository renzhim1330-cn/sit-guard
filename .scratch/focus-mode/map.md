## Notes

- **领域**：儿童坐姿提醒 App（sit-guard）的专注模式增强——减少屏幕视觉干扰（孩子不看屏幕、保护视力），检测 / 提醒功能不受影响
- **载体**：沿用现有 `app/`（measure.js / engine.js / voice.js），纯前端，手机 / 平板浏览器
- **每会话必读技能**：`grilling`、`domain-modeling`；原型票会话加 `prototype`
- **已定决策速记**（细节见各票）：形态 = 应用内黑屏遮罩 + **唤醒锁**（Screen Wake Lock，iOS 16.4+/Chrome 84+，HTTPS，文档不可见即释放）防自动锁屏，**系统锁屏 = 平台约束排除**；进入 = 开始学习 → 圆环倒计时 5s（右下角「取消」按钮；文案含「指示灯亮 = 守护中」）→ 黑屏；黑屏 = 全黑 + 极暗吉祥物剪影 + 左下角半透明「结束专注」药丸按钮（单击 = 回正常界面，可再进）；反馈 = 仅语音、黑屏期间完全静默；降级 = 无唤醒锁设备进入前提示后仍可用；锁屏恢复 = visibilitychange/pageshow 自动重取摄像头重启检测、基准丢失提示重校准、时长暂停；小结沿用现有

## Decisions so far

- [浏览器屏幕常亮与后台运行能力边界](issues/01-browser-wakelock-research.md) — 黑屏遮罩不影响检测 ✓；Wake Lock 是唯一防锁屏手段（iOS 16.4+/Chrome 84+，HTTPS，文档不可见即释放）；锁屏后无任何 API 可后台运行；iOS standalone PWA 的 Wake Lock 不可靠 + 内存压力可能重载页面 → 恢复逻辑必须健壮；vibrate iOS 不支持（仅语音正确）；OLED 黑屏省电、LCD 不省
- [专注模式交互原型](issues/02-focus-mode-prototype.md) — 主理人实机体验定稿：胜出变体 B「圆环安抚」（绿色圆环 5 秒倒计时 + 文案「闭上眼睛，专注开始」）；黑屏 = 全黑 + 极暗吉祥物剪影 + 左下角半透明「结束专注」药丸按钮单击退出；无唤醒锁设备降级 = 进入前提示后仍可用；原型资产 `prototypes/focus-mode.html`
- [专注模式的交互与降级策略决策](issues/03-focus-mode-decisions.md) — 收尾决策：黑屏期间完全静默（指示灯 + 剪影承担"守护中"）；倒计时文案提一句「指示灯亮 = 守护中」；「结束专注」= 回正常界面可再进（「结束学习」才出小结）；小结沿用现有不新增；锁屏恢复 = 自动恢复 + 基准丢失提示重校准 + 时长暂停；倒计时右下角显式「取消」按钮

## Out of scope

- **系统锁屏 + 程序后台运行**——浏览器平台不允许（纯 Web 无 API 可在屏幕关闭时运行；Wake Lock 只能阻止锁屏），目的地是黑屏遮罩
- **家长远程监控 / 另一设备查看状态**（沿用旧地图排除）
- **屏幕完全关闭（OS 级）的任何变通**（如特制系统设置引导仅限降级提示，不做自动化）
- **桌面浏览器**（专注场景为手机 / 平板）
