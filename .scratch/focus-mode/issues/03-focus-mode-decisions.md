## Answer

**全部决策定稿（主理人 2026-08-16 逐项确认，均跟随推荐）：**

1. **黑屏期间感知：完全静默**——不设定时轻响；「程序还活着」由系统摄像头指示灯（iOS 绿点 / Android 相机指示，黑屏下仍显示）+ 极暗吉祥物剪影承担；定时响声对写作业的孩子是噪音
2. **摄像头指示灯文案：纳入，仅提一次**——倒计时文案中顺带一句「指示灯亮 = 守护中」，不重复打扰
3. **「结束专注」语义：退出黑屏 = 回到正常界面继续学习**（可再次点「进入专注」重新黑屏）；「结束学习」才结束时段出小结
4. **小结：沿用现有小结，不新增统计**——学习时长 / 良好时长 / 提醒 / 表扬已覆盖全部所需
5. **锁屏恢复：自动恢复 + 基准丢失提示重校准**——visibilitychange / pageshow 时自动重取摄像头、重启检测会话；若页面被重载导致基准（内存）丢失，提示重新校准；锁屏期间学习时长暂停，回来后继续（复用现有「离开」暂停计时逻辑的思路）
6. **倒计时取消：显式「取消」按钮**——倒计时层右下角小按钮，单击回主界面（防孩子乱点误触；不采用点任意处取消）

**实现要点（供实施，2026-08-16）：** 专注模式 = 现有学习流程上的覆盖层 + 唤醒锁：开始学习 →（校准已有）→ 圆环倒计时 5s（含「取消」按钮与「指示灯亮 = 守护中」一句文案）→ 黑屏遮罩（全黑 + 极暗吉祥物剪影 + 左下角「结束专注」药丸）→ 退出回正常界面；唤醒锁在用户手势内 request + visibilitychange 重取 + try/catch，失败降级为进入前提示（文案见原型票）；恢复逻辑见第 5 条；全部沿用 measure.js / engine.js / voice.js，纯前端。
