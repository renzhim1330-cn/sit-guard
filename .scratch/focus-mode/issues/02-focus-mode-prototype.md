# 专注模式交互原型

## Question

「开始学习 → 提示「马上进入专注模式」→ 5 秒倒计时 → 纯黑遮罩（左下角小按钮退出）→ 仅语音反馈」这套交互长什么样、手感如何？

用粗糙原型把交互细节拉高到可体验的程度：倒计时的呈现方式（数字 / 圆环 / 无）、提示文案、退出按钮的位置 / 大小 / 透明度 / 点击反馈（是否震动 / 是否弹确认）、进入与退出动画、黑屏遮罩的纯黑程度（要不要极暗的吉祥物剪影占位）。

解析方式：`/prototype` 会话，产出一次性原型 HTML 资产并在本票链接；交互细节的最终决策归「专注模式的交互与降级策略决策」票。

## Prototype（资产）

- 原型文件：`prototypes/focus-mode.html`——双击即开、无网络依赖、一次性（throwaway）；3 个结构不同的变体用 `?variant=A|B|C` 或底部栏切换：A 数字极简 / B 圆环安抚 / C 渐隐沉浸；含「模拟无唤醒锁设备」降级提示、黑屏内模拟提醒（真实 TTS 语音）、退出后小结
- 验证对象：进入流程（提示 → 倒计时 → 黑屏）、黑屏的纯黑程度与退出入口形态、降级提示文案、小结内容

## Answer

**交互定稿（主理人实机体验 4 项全部确认，2026-08-16）：**

1. **胜出变体：B「圆环安抚」**——绿色圆环倒计时（5 秒）+ 数字 + 文案「闭上眼睛，专注开始」；进入动效为圆环递减而非数字跳动，对低龄孩子更安抚
2. **黑屏退出入口：显式按钮**（A/B 形态）——左下角半透明「结束专注」药丸按钮，单击即退（不做 C 的微点+确认两步）；纯黑程度 = 全黑 + 极暗吉祥物剪影（保留「程序还在」的锚点）
3. **降级策略：提示后仍可用**——检测不到唤醒锁时进入前显示提示（文案：本设备无法保持屏幕常亮，可能锁屏，建议把系统自动锁屏设为永不），不阻断使用
4. **倒计时时长：5 秒**

**原型其余特性随决策票定夺**：黑屏期间「还在运行」感知、摄像头指示灯文案、小结是否加「专注时长 / 提醒次数」统计、误按电源键锁屏后的恢复。
