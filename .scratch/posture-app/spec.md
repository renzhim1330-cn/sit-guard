# 儿童坐姿提醒 Web App — MVP 规格说明

> 来源：wayfinder 地图 `.scratch/posture-app/map.md` 及其 7 张决策票（01–07）。本文是把已定决议汇编成的、可交给开发实施的 MVP 规格。

---

## 1. 产品定位

一个**自我纠正型**坐姿提醒工具：6–12 岁儿童在书桌前写作业 / 上网课时，用手机 / 平板前置摄像头实时检测不良坐姿，及时播放温和的预录语音，提醒孩子自己坐正。孩子听到语音后主动纠正，**非**家长远程监控。

定位为**儿童创意作品**：轻量、纯前端、可现场演示，不追求生产级工程。

---

## 2. 用户与场景

- **用户**：6–12 岁小学生（单用户，无账号 / 多档案）
- **场景**：书桌前写作业 / 上网课；手机 / 平板立在书桌前方，前置摄像头朝向孩子
- **屏幕形态**：手机竖屏优先 + 平板横屏「能用就行」（简单响应式）

| 功能 | 说明 |
|---|---|

## 4. 检测与判定

### 4.1 技术选型（票 01）

- **库**：MediaPipe Pose Landmarker，npm 包 `@mediapipe/tasks-vision@1.0.1`（锁定版本，勿用 `@latest`）
- **模型**：`pose_landmarker_lite`（≈5.5 MB），输出 33 关键点 + 3D world landmarks（米制，髋中心为原点）
- **加载**：CDN（见 §8），`runningMode: "VIDEO"`，`numPoses: 1`，`delegate: "GPU"`（老设备回退 `"CPU"`/WASM）
- **线程**：`detectForVideo()` 放进 Web Worker，避免阻塞主线程
- **性能**：中端手机 / iPad 9 代 ≥20 FPS；`requestAnimationFrame` 按需采样，关闭 `outputSegmentationMasks` 降负载

### 4.2 度量（`measurePose`，关键点 → 三个度量）

| 度量 | 公式 | 方向 |
|---|---|---|
| 驼背 | 髋中点→肩中点矢量与竖直方向的夹角（度） | 前倾为正 |
| 头过低 | (肩中点.y − 鼻.y) ÷ 躯干长（无量纲，尺度无关） | 越小越低 |
| 侧倾 | 耳线、肩线相对水平倾角的较大者（度） | 越大越歪 |

> ⚠️ **待验证（不阻塞开发）**：`measurePose` 的坐标约定（y 轴方向、z 轴正负）需在真实数据上确认一次——**实现期直接用摄像头实拍即可**（打印关键点或看骨架演示模式），无需预拍素材。这是实现期唯一的技术未知项。

### 4.3 判定状态机（票 02）

- **校准**：捕获当前三个度量为**基准 baseline**
- **偏离**：`d = |当前度量 − baseline|`（阈值一律以偏离计，不以绝对值计）
- **状态带**：`正常`（d < t1）→ `疑似`（t1 ≤ d < t2）→ `超标`（d ≥ t2）
- **迟滞**：进带用阈值 T，出带用 T − hys（防边界抖动）
- **宽限**：仅 `超标` 状态持续计时，满 **7s** 才触发提醒
- **不做度量平滑**：EMA 平滑会让偏离值渐近逼近阈值、边界永远触发不了（原型实测 bug）；抗误报交给「迟滞 + 宽限」
- **提醒裁决**：同一刻只发一条，取相对阈值偏离最大者（d/t2）；**不改正就一直提醒**——提醒 → 冷却 30s → 仍超标 → 再计宽限 → 再提醒，无次数上限
- **宽限冻结**：宽限仅在超标期间累计；短暂脱离超标带（边界抖动）与冷却压住期间**不清零**，真正改正（全部姿态回到正常并保持 6s）才清零重来
- **坐正表扬**：三个姿态**全部**处于「正常」并保持 6s、且本次全绿周期内确实出现过超标，才表扬；一次恢复只表扬一次（最小间隔 ≥20s）；任一姿态超标 / 疑似则不表扬

### 4.4 阈值（偏离量；已按票 05 素材校准，票 08 验收）

| 姿态 | 疑似 t1 | 超标 t2 | 迟滞 hys |
|---|---|---|---|
| 驼背 | 8° | 12° | 2° |
| 头过低 | 10% | 16% | 3% |
| 侧倾 | 6° | 12° | 2° |

> 校准依据：`test-assets/analysis-results.md`（七段素材实测各档偏离分布）。头过低 t1 由 12% 下调至 10% 使中度档稳定进入疑似、t2 由 20% 下调至 16%；驼背维持——轻度与正常动作分布重叠，t1 不宜下调；侧倾 t1 由 8° 下调至 6°（修复 tilt 公式后实测：正常动作 >6° 仅 4–8% 且为短尖峰、歪头/歪身 42% 入疑似），t2=12° 保持（歪头 max 11.9° 不提醒、歪身 P75 15.6° 持续超标会提醒）。侧倾缺「重度」档素材，t2 为语义折中。

> 应用内「⚙️ 参数设置」（页脚入口）可在运行时动态调整以上阈值与时间参数（宽限 / 冷却 / 表扬间隔），改动立即生效并保存在本地（localStorage）；含「宽松 / 标准 / 严格」三档灵敏度预设与一键恢复默认（标准=本表）。

## 5. 界面（票 03，方案 B「学习驾驶舱」）

- **头栏**：品牌名「坐姿小卫士」+ 状态点（颜色随状态）+ 状态标签
- **卡片① 我的坐姿**：吉祥物（84px）+ 状态语 + 「重新校准」按钮
- **卡片② 学习时段**：40:00 大号倒计时 + 「开始 / 结束」+ 已提醒次数
- **卡片③ 提醒语音**：预录列表 + 「▶ 试听」+ 「＋ 添加家长 / 老师录音」
- **卡片④ 今日小结**：良好时长 / 提醒次数 / 坐正次数（v1 三项统计）
- **页脚**：「🎬 骨架演示模式」入口
- **吉祥物**：纯色小圆怪，随状态换表情与配色（正常=绿+微笑；疑似=黄+担忧；超标/提醒=红+皱眉/张口；离开=灰+问号）
- **共用覆盖层（模式，非布局）**：校准（一键式）、语音列表、骨架演示（摄像头 + 关键点叠加）
- **不显示摄像头原始画面**（除演示模式）

---

## 6. 语音（票 04，文案库定稿）

### 6.1 不良提醒（按姿态区分，每类 2 条随机轮换、不连播、始终温和不升级）

| 姿态 | 第 1 条 | 第 2 条 |
|---|---|---|
| 驼背 | 背挺直～ | 背要挺直哦～ |
| 头过低 | 头抬起来一点哦～ | 脑袋抬起来一点～ |
| 侧倾 | 身体坐正，别歪哦～ | 坐直一点，别歪啦～ |
| 兜底（检测不清） | 坐端正哦～ | 换个舒服又端正的姿势～ |

### 6.2 坐正表扬（离开超标带时，≥20s 间隔）

坐正啦，真棒！ ｜ 背挺直了，真棒！ ｜ 好样的，继续保持～

### 6.3 时段提示

- 开始学习：开始学习啦，加油～
- 结束学习：学习结束，休息一下吧～
- （无中途休息提示——票 06 已定 v1 不做中途休息）

### 6.4 频率参数（终值）

| 参数 | 值 |
|---|---|
| 宽限时间 | 7s（宽松 10s / 标准 7s / 严格 5s） |
| 提醒冷却 | ≥30s |
| 提醒循环 | 不改正则无限循环提醒（无次数上限） |
| 表扬条件 | 全绿（正常）保持 6s + 本次确有超标；一次恢复只表扬一次 |
| 表扬最小间隔 | ≥20s |
| 语气升级 | 不升级，始终温和 |

- 风格：温和第二人称、不带称呼（6–12 岁跨度）；语音由家长 / 老师**预录**
- 开始 / 结束提示音与坐姿提醒独立，不占冷却

## 7. 状态与异常处理（票 07）

### 7.1 检测丢失三档

| 丢失时长 | 行为 |
|---|---|
| <5s | 忽略（瞬抖），计时照走，界面无变化 |
| ≥5s | 进入「离开」状态：吉祥物变「找不到你」（灰 + 问号）+ 文字「看不到你啦，坐回来吧～」；**暂停**学习时段计时；**抑制所有坐姿提醒** |
| ≥30s | 视觉强化提示；不播催回语音 |

### 7.2 恢复检测后

- 沿用原校准基准（设备没动，不强制重新校准）
- **宽限计时清零**重来（防「离开前快满宽限、坐回来立刻响」）
- 冷却计时照走

### 7.3 多人入镜（numPoses=1）

- MVP 不特殊处理：MediaPipe 挑最显著的人，跳变由宽限 3.5s + 冷却 30s 吸收；选人逻辑放 v2

## 8. 技术方案与部署

- **形态**：纯前端网页 App（PWA），无后端
- **姿态估计**：MediaPipe Pose Landmarker lite，全程设备本地推理，视频不上传
- **加载方式**（CDN，锁定版本）：

```html
<script src="https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@1.0.1/vision_bundle.mjs" crossorigin="anonymous"></script>
```

```js
const vision = await FilesetResolver.forVisionTasks(
  "https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@1.0.1/wasm"
);
const poseLandmarker = await PoseLandmarker.createFromOptions(vision, {
  baseOptions: {
    modelAssetPath:
      "https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/latest/pose_landmarker_lite.task",
    delegate: "GPU",          // WebGL2；老设备回退 "CPU"
  },
  runningMode: "VIDEO",
  numPoses: 1,
});
```

- **线程**：检测放 Web Worker（官方示例 pose-landmarker.worker）
- **兼容性**：iOS Safari 15+（WebGL2 加速分水岭）、Android Chrome 56+；**不依赖 WebGPU**
- **硬约束**：前置摄像头需 **HTTPS**（或 localhost）——现场演示必须 HTTPS 部署，`http://` 局域网 IP 拿不到摄像头
- **存储**：localStorage 存最近 7 次小结
