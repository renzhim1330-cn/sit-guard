# 界面与吉祥物交互

## Question

界面长什么样？

- **主界面**：卡通吉祥物 + 坐姿状态（坐得好 = 开心，坐得差 = 提醒表情），不放摄像头原始画面
- **附带**：可切换的骨架叠加演示模式（展示用，证明检测是真的）
- **其余**：开始 / 结束学习时段（默认 40 分钟倒计时）、校准按钮、语音试听与设置、本次小结（若「MVP 功能边界与分期」决定纳入）

解析方式：`/prototype` 会话——出界面稿 / 可点原型，链接作为资产附到本文件，`## Answer` 记录定稿要点。

## Answer

**胜出方案：B「学习驾驶舱」**（用户确认，原型无需再改）。

- **整体布局**：头栏（品牌名 + 状态点 + 状态标签）+ 四张卡片：① 我的坐姿（吉祥物 + 状态语 + 重新校准）② 学习时段（40 分钟倒计时 + 开始/结束 + 已提醒次数）③ 提醒语音（预录列表 + 试听 + 添加家长/老师录音）④ 今日小结（良好时长/提醒/坐正表扬三项统计，形式待票 06）；页脚「骨架演示模式」入口。
- **吉祥物**：纯色小圆怪，随状态换表情与配色（正常=绿+微笑，疑似=黄+担忧，超标/提醒=红+皱眉/张口），各状态配一句文字；不含摄像头原始画面。
- **共用覆盖层（模式，非布局）**：校准（「我坐好了，点这里」一键式）、语音列表、骨架演示（摄像头画面 + 关键点叠加，仅演示用）。
- **移交其它票**：小结形式 → 票 06；语音文案定稿 → 票 04；出画/丢失状态 → 票 07。
- 原型资产（含全部三方案，作为 primary source 保留）：`prototypes/03-ui-mascot.html`。
