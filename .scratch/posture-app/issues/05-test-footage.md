# 采集测试素材

## Question

采集真实测试素材，供「不良坐姿判定阈值与校准」调阈值用。

按清单拍摄（同一孩子；手机 / 平板摆在书桌前方，机位与真实使用一致；光线正常；各 15–30 秒）：

1. 标准坐姿（坐好基准）
2. 轻度 / 中度 / 重度驼背
3. 头过低（下巴贴近桌面）
4. 侧倾（歪头 / 歪身）
5. 正常小动作（喝水、翻书、抬头看屏幕）——用于验证抗误报

解析：视频存到 `test-assets/`（或与主理人商定的位置），本文件 `## Answer` 记录文件清单与拍摄参数（设备、机位、光线）。

## Guide

手把手的拍摄指导（机位 / 光线 / 每个场景的拍法 / 避坑清单）见 `test-assets/README.md`。
