# 出画与多人入镜的处理策略

## Question

技术已定：MediaPipe Pose Landmarker（`numPoses: 1`，单人）。需要定「检测不到人 / 多人」时的行为策略：

- **离开画面 / 被遮挡**（检测不到人）：学习时段计时暂停还是继续？吉祥物显示什么状态？是否抑制提醒（避免孩子离开后语音空放）？
- **多人入镜**（家人路过等）：`numPoses: 1` 时会挑出画面中的一个人——要不要处理？如何处理？
- **坐回后恢复检测**：沿用原校准基准，还是重新校准？宽限计时器与冷却计时器如何重置？
- **短暂丢失 vs 长时间丢失**（如 1–2 秒内恢复 vs 超过 30 秒）是否区别对待？

解析方式：`/grilling` 会话，答案记录到本文件 `## Answer`。

## Answer

**检测丢失三档（用户确认）：**
- **<5s 瞬抖**：忽略，计时照走，界面无变化
- **≥5s**：进入「离开」状态——吉祥物「找不到你」（灰色 + 问号表情）+ 文字「看不到你啦，坐回来吧～」；**暂停**学习时段计时；**抑制所有坐姿提醒**
- **≥30s**：视觉强化提示；不播催回语音（不扩充票 04 已定稿文案库）

**恢复检测后：** 沿用原校准基准（设备没动，基准仍有效，不强制重新校准）；**宽限计时清零**重来（防"离开前快满宽限、坐回来立刻响"）；冷却计时照走。

**多人入镜（numPoses=1）：** MVP 不特殊处理——MediaPipe 挑最显著的人，跳变由宽限 3.5s + 冷却 30s 自然吸收；多人选人逻辑放 v2。

**移交实现：** 状态机在判定层之外新增「检测健康」档（检测到 / 离开中），吉祥物新增离开 mood；界面文案用上表定稿。
