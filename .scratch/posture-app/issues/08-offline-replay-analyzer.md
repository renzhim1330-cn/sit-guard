# 离线回放分析页（调阈值）

## Question

做一个离线工具：浏览器打开 → 选「[采集测试素材](05-test-footage.md)」票拍的本地视频 →
本地逐帧回放成三个度量的轨迹，量化「轻度 / 中度 / 重度」各档的偏离分布。

它解除的决策：把阈值初值（驼背 / 侧倾 8°/12°、头过低 12%/20%）换成**有数据支撑**的值，
并沉淀抗误报回归基线（以后每次改算法跑一遍全部素材对比）。
分析页开发不依赖素材（可先做）；素材到位后用它验收并产出阈值建议，由主理人确认后更新 `app.js` 的 `CFG`。

## Requirements

- 独立页面（`app/analyzer.html` + `analyzer.js`），浏览器打开 → 选本地视频 → 本地逐帧检测；**视频不上传**
- **复用 `measure.js` 的度量公式**（与 App 完全一致——分析结果才能直接迁移为阈值）
- 输出：
  - 三度量逐帧轨迹（canvas 折线，支持缩放 / 平移）
  - 基准选取：默认取开头「标准坐」段，支持手动框选任意时间段做校准基准
  - 偏离分布：按姿态给直方图 / 分位数（P25 / P50 / P75），按「标准→动作→回正」台阶自动切分并输出各档均值
  - 用当前阈值（含迟滞 / 宽限）标出哪些帧会触发提醒，回放可视化
  - 阈值建议：按各档偏离分布给出 t1 / t2 建议值（落在档位之间的分隔点）
- 抗误报验证：「正常小动作」素材跑一遍，统计误报帧数

## Acceptance

- 加载 6 段素材（`01-baseline` ~ `06-actions`）能产出「每档偏离均值 + 阈值建议」表
- 与 App 内实时检测的度量值一致：同一帧离线回放与在线摄像头检测数值相同（同模型同公式）
- 本地运行，无需部署；`README.md` 记录使用方法

## Answer

**已实现：`app/analyzer.html` + `analyzer.js`（Chrome / Edge 双击即用，本地处理、视频不上传；用法见 `app/README.md`「离线分析」节）。**

- **复用与 App 完全一致的公式与引擎**：同一 MediaPipe lite 模型 + 同一 `measure.js` 度量公式 + 同一 `engine.js` 判定引擎——离线回放与在线检测数值相同由构造保证（验收项②）
- **流程**：选本地视频 → 逐帧检测 → 自动取开头「标准坐」段为基准（可在轨迹图上按住拖动框选任意时段改基准）→ 自动切分「标准→动作→回正」台阶（按主导度量 + 严重度三等分自动命名「驼背-轻/中/重…」；低于 t1 的段叫「动作段」），也可手动在偏离图上拖选区间
- **输出**：
  - 三度量逐帧轨迹（滚轮缩放 / Alt 平移 / 双击复位 / 单击回放定位到该帧）
  - 区间统计表：每档 均值 / P25 / P50 / P75 / max（偏离值，显示单位）
  - 每姿态偏离直方图（12 档，标注 t1/t2 所在档位）+ 各档分布
  - 阈值建议：t1/t2 = 轻↔中、中↔重两档的 P75↔P25 分界；正常动作 max 超建议 t1 时给出误报警告
  - 提醒模拟：按页内可调的 t1/t2/迟滞/宽限/冷却跑同一引擎，红竖线 ▲ 标出会触发提醒的帧与时刻清单
  - 抗误报：区间名含「正常」的段统计超标帧数/占比 + 触发提醒次数
  - 导出 CSV：每帧原始度量 + 偏离 + 区间统计 + 提醒清单（留存作回归基线对比）
- 阈值 / 宽限页内可改，建议与提醒模拟即时重算

**数据支撑部分待票 05 素材到位后验收（素材未拍摄，本次不阻塞交付）：**

1. 加载 `01-baseline` ~ `06-actions` 六段素材 → 产出「每档偏离均值 + 阈值建议」表 → 由主理人确认后更新 `app.js` 的 `CFG`（含「标准」预设）
2. `06-actions` 跑一遍统计误报帧数，沉淀抗误报回归基线
3. 验收项②「离线与在线数值一致」已由构造保证（同模型同公式），素材到位后实拍复核一次

**算法自检（开发期，node 合成数据）**：引擎模拟三场景通过（超标 3.5s 触发→冷却 30s 再触发；回正 6s 宽限清零；头过低显示/原始单位换算）；自动切分五场景通过（驼背轻中重 / 正常小动作 / 歪头两段 / 低头轻中重 / 纯基准无段）。
