# MVP 功能边界与分期

## Question

MVP 的功能边界与分期：

- v1 必须有什么？（已定：驼背 / 头过低 / 侧倾检测 + 轻量校准 + 吉祥物主界面 + 学习时段 + 预录语音提醒——还有遗漏吗？）
- 骨架演示模式进 v1 还是 v2？
- 「本次坐姿小结 / 评分」进 v1 吗？什么形式？
- 趴桌、离屏太近等后续姿态如何排期？
- 交付的 spec 里分期计划如何写？

解析方式：`/grilling` 会话，答案记录到本文件 `## Answer`。

## Answer

**v1（MVP，完整实现）：**
- 三类姿态检测（驼背 / 头过低 / 侧倾）；`measure()` 坐标约定用票 05 素材验证
- 轻量一键校准
- 界面方案 B「学习驾驶舱」+ 吉祥物随状态换表情配色
- 骨架演示模式（v1）
- 学习时段：手动开始 / 结束、默认 40 分钟、**无中途休息**（到点结束即休息）；支持暂停 / 继续
- 预录语音：票 04 定稿文案库 + 频率终值（宽限 3.5s / 冷却 30s / 同类 ≤2 / 表扬 ≥20s / 不升级）
- 坐姿小结：每次结束显示「良好时长 / 提醒次数 / 坐正次数」三项
- 历史：localStorage 存最近 7 次小结（无后端）
- 基本设置并入界面：音量 / 静音、语音试听、校准引导、暂停继续
- 适配：手机竖屏优先 + 平板横屏「能用就行」（简单响应式）
- 技术栈（票 01）：MediaPipe Pose Landmarker lite `@mediapipe/tasks-vision@1.0.1` CDN、纯前端、Web Worker、HTTPS 或 localhost

**v2（路线图，仅列入 spec 分期，不做细节）：**
- 复杂评分 / 坐姿趋势图
- 趴桌、离屏太近检测（需另开阈值原型票）
- 中途休息 / 番茄钟（可选）
- 更丰富吉祥物 / 皮肤、更多语音轮换

**Out of scope（沿用地图声明）：** 家长远程监控、后端 / 账号、教室多设备、隐私合规（创意作品定位）、打包上架。

**Spec 骨架（分期计划写法）：** 按「产品定位 → 用户与场景 → 功能清单（v1 全量 / v2 路线图）→ 检测与判定（票 01+02）→ 界面（票 03）→ 语音（票 04）→ 状态与异常处理（票 07）→ 技术方案与部署 → 分期计划」组织。
