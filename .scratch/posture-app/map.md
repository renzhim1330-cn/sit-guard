# 儿童坐姿提醒 App — 地图

## Destination

本地图的终点：一份可直接交给开发实施的 **MVP 完整规格说明**（产品定义 + 技术选型 + 分期计划）——《儿童坐姿提醒》Web App：6–12 岁儿童在书桌前写作业 / 上网课时，用手机 / 平板前置摄像头实时检测**驼背、头过低、侧倾**三类不良坐姿，连续 **3–5 秒宽限**后播放温和的**预录语音**提醒孩子坐正。所有决策票解析完毕后，spec 所需内容即齐备。

## Notes

- **领域**：儿童坐姿提醒，自我纠正型（孩子自己听到语音后坐正，非家长远程监控）
- **载体（已定）**：网页 App（PWA），手机 / 平板浏览器 + 前置摄像头，姿态估计全程在设备本地完成
- **每会话必读技能**：`grilling`、`domain-modeling`；原型票会话加 `prototype`
- **立场**：儿童创意作品定位——轻量、可现场演示、不追求生产级工程；对话用中文；用户多数选择跟随推荐
- **已定决策速记**（细节见各票）：检测驼背 / 头过低 / 侧倾；3–5s 宽限；家长 / 老师预录温和语音；提醒间隔 ≥30s、同一姿态连续 ≤2 次；手动开始 / 结束学习时段（默认 40 分钟）；开始前轻量校准；吉祥物 UI + 可切换骨架演示模式；MVP 不含家长报告

- [语音文案、语气与频率](issues/04-voice-script.md) — 文案库定稿：按姿态区分、每类 2 条随机轮换不连播、温和第二人称不升级；参数终值：宽限 3.5s / 冷却 30s / 同类 ≤2 / 表扬 ≥20s；开始+结束提示，休息待票 06
- [MVP 功能边界与分期](issues/06-mvp-scope.md) — v1 定案：骨架演示/小结(简单统计)/本地 7 次历史进 v1；趴桌·离屏、评分趋势、番茄钟进 v2；v1 无中途休息；基本设置并入界面

- [采集测试素材](issues/05-test-footage.md) — 7 段素材到位（手机竖拍前置、书桌前方约 1 米、顺光/侧光），01-baseline~06-actions；拍摄参数与验证进展见票内，分析报告见 `test-assets/analysis-results.md`
